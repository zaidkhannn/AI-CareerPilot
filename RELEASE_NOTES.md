# Release Notes

## AI-CareerPilot v1.0.0
**Initial Release**

### Included Features
- **Main Dashboard:** Dynamic glassmorphic UI giving access to all tools.
- **Career Roadmap Mapping:** Generates Markdown-based study and learning roadmaps based on role, skill level, and study time.
- **Voice Interview Simulator:** Fully voice-based interaction with "Black Widow" AI persona using Android TTS and STT.
- **Target Answer Help Mode:** Ask the simulator for help when stuck during an interview.
- **Resume Analyzer:** Checks resume quality and provides insights.
- **Technical Assessment:** Practice domain-specific technical questions.
- **Dream Job Planner:** Goal setting and career planning.
- **Mentor Connect:** Interface for seeking expert guidance.

### Requirements
- **Minimum OS:** Android 7.0 (Nougat, API 24) or higher.
- **Permissions:** 
  - Microphone access (required for Interview Simulator).
  - Internet access (required to communicate with Groq AI API).

### Installation
1. Download `AI-CareerPilot-v1.0.0.apk` from the Releases section.
2. Open the downloaded file on your Android device.
3. If prompted, allow your browser/file manager to install applications from unknown sources.
4. Complete the installation and open the application.
