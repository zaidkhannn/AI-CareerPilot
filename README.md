# AI-CareerPilot

**AI-CareerPilot** is an AI-powered career companion Android application designed to provide personalized career roadmaps, conduct voice-based interview simulations, analyze resumes, and evaluate technical skills using large language models.

## Overview

AI-CareerPilot is designed for students, job seekers, and early-career professionals who need structured guidance and realistic interview practice. The application acts as a personal career mentor, leveraging the Groq API (Qwen 3.8-27b) to deliver tailored advice, dynamic career path mapping, and real-time voice interview simulations.

## Key Features

- **Career Roadmap Mapping:** Generates detailed, phase-by-phase Markdown learning roadmaps based on the user's target role, current skill level, and daily study time commitment.
- **Voice Interview Simulator:** An immersive voice-to-voice interview experience using Android's native Text-to-Speech (TTS) and Speech Recognition, driven by an elite "Black Widow" AI persona. Includes adaptive questioning, real-time feedback, and a "Help Mode" for target answers.
- **Resume Analyzer:** Reviews resumes against ATS standards and provides actionable feedback.
- **Technical Assessment:** Evaluates technical skills with targeted questions.
- **Mentor Connect:** Offers expert guidance on career progression.
- **Dream Job Planner:** Helps users plan long-term career goals.

## Technology Stack

- **Platform:** Android SDK
- **Language:** Java
- **UI Framework:** Android XML Layouts, Material Design
- **AI Integration:** Groq API (REST API)
- **Voice Engine:** Android TextToSpeech (TTS), Android SpeechRecognizer (STT)
- **Markdown Rendering:** Markwon (Core, Strikethrough, Tables)
- **Networking:** OkHttp3
- **Local Storage:** SharedPreferences

## Architecture

- **UI Layer:** Activities (e.g., `MainActivity`, `CareerRoadmapActivity`, `InterviewSimulatorActivity`) handling UI rendering and user interactions.
- **Application Logic:** Embedded within Activities. Event-driven flow handling user inputs and transitions.
- **Data Layer:** `SharedPreferences` for session management and user profile data.
- **API Layer:** `GroqApiService` provides an asynchronous interface to the Groq API using `OkHttp3`, executing network calls on a background thread and posting results back to the main thread via a callback interface.
- **AI Integration:** Prompts are dynamically generated within the app based on user inputs and sent to Groq. The responses are parsed, sanitized (removing thinking blocks), and presented via UI or TTS.

## Project Structure

- `app/src/main/java/com/techiguru/aicareerpilot/`: Contains all Java source files.
  - `MainActivity.java`: Main dashboard.
  - `CareerRoadmapActivity.java`: Generates and displays the AI roadmap.
  - `InterviewSimulatorActivity.java`: Core logic for the voice-based interview.
  - `GroqApiService.java`: Networking class managing API calls to Groq.
- `app/src/main/res/`: Contains XML layouts, drawable resources, colors, and themes.
- `app/build.gradle`: Manages dependencies and build configurations.

## AI Integration

The application integrates with the Groq API (specifically `qwen/qwen3.8-27b`) via the `GroqApiService`. 
- **Prompt Engineering:** Strict system instructions are sent to the AI to enforce JSON-free, well-formatted Markdown outputs for roadmaps, and concise, feedback-oriented conversational responses for the interview simulator.
- **Handling Responses:** The app parses the `choices` array from the Groq JSON response, sanitizes the text (e.g., stripping `<think>` tags from Qwen models), and routes the content either to the `Markwon` renderer or the TextToSpeech engine.

## Installation — APK

Download the latest AI-CareerPilot APK to install on your device.

1. Download the latest `AI-CareerPilot-v1.0.0.apk` from the GitHub Releases section.
2. Open the APK on an Android device.
3. Android may request permission to install applications from unknown sources. Allow the permission if required.
4. Install AI-CareerPilot.
5. Launch the application.

*Minimum Android Version: Android 7.0 (Nougat, API 24)*
*Requires an active Internet connection and Microphone permissions for the simulator.*

## Run From Source

1. Clone the repository: `git clone https://github.com/zaidkhannn/AI-CareerPilot.git`
2. Open the project in Android Studio.
3. Sync Gradle.
4. In the root directory, create a `local.properties` file (if not present) and add your Groq API key:
   ```properties
   GROQ_API_KEY=your_api_key_here
   ```
5. Connect an Android device or start an emulator.
6. Click **Run** in Android Studio.
