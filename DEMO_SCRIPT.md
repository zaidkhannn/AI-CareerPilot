# AI-CareerPilot Demo Video Script

**Target Duration:** 60 - 90 seconds
**Format:** Screen recording of the actual application running on an Android device.

---

### Sequence 1: Application Launch & Dashboard (0:00 - 0:10)
- **Action:** Tap the AI-CareerPilot icon to launch the application.
- **Visual:** The Splash screen transitions smoothly into the Main Dashboard.
- **Narration/Caption:** "Welcome to AI-CareerPilot, your personal AI-powered career companion."
- **Action:** Briefly scroll the dashboard to show the glassmorphic feature cards (Career Roadmap, Interview Prep, Resume Analyzer, etc.).

### Sequence 2: Generating a Career Roadmap (0:10 - 0:30)
- **Action:** Tap on the **Career Roadmap** card.
- **Action:** Select "Software Engineer" as the role, "Intermediate" as the skill level, and "2 Hours" for study time.
- **Action:** Tap "Generate Roadmap".
- **Visual:** Show the loading indicator, then the rich Markdown output appearing.
- **Narration/Caption:** "Generate personalized, phase-by-phase learning paths instantly."
- **Action:** Scroll through the generated Markdown document to highlight headings, lists, and formatting.

### Sequence 3: Voice Interview Simulator (0:30 - 1:10)
- **Action:** Navigate back to the Dashboard and tap **Interview Prep** (or Simulator).
- **Action:** Configure the interview settings and start the simulation.
- **Visual:** The Interview Simulator UI opens. The "AI is speaking..." badge appears.
- **Audio:** The TTS voice ("Black Widow") introduces itself and asks the first question ("Introduce yourself").
- **Action:** Tap the Mic button. The "Listening..." badge appears.
- **Audio (User):** "Hi, I am a software engineering student with experience in Android development."
- **Visual:** The Speech-To-Text transcribes the speech in real-time. The app shows "Processing answer...".
- **Audio (AI):** The AI provides short feedback ("Good answer...") and asks a follow-up question.
- **Narration/Caption:** "Practice real voice interviews with adaptive AI questioning and real-time feedback."

### Sequence 4: Help Mode Demonstration (1:10 - 1:25)
- **Action:** Tap the Mic button and say, "I'm not sure how to answer that."
- **Visual:** The "Target Answer loading..." badge appears.
- **Audio (AI):** The AI explains the concept concisely without breaking character, then asks a new question.
- **Narration/Caption:** "Stuck? The AI acts as a mentor to provide target answers."

### Sequence 5: End Interview & Evaluation (1:25 - 1:30)
- **Action:** Tap the End Interview button.
- **Visual:** The simulation concludes and the Evaluation screen is displayed with a score, strengths, and weaknesses.
- **Narration/Caption:** "Get comprehensive post-interview feedback to improve your skills."
- **Action:** Return to the Dashboard and end the recording.

---

**Preparation Checklist Before Recording:**
- Ensure you have a stable internet connection.
- Ensure the Groq API key is properly configured in `local.properties`.
- Use a quiet room so the Speech-to-Text captures your voice perfectly.
- Make sure "Do Not Disturb" is active on the device to prevent notifications during recording.
